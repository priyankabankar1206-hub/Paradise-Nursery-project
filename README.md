# Paradise Nursery - Online Plant Shop Application

Paradise Nursery is an e-commerce web application built using **React** and **Redux Toolkit**. It offers plant enthusiasts a seamless shopping experience to browse, select, and purchase various indoor and outdoor plants.

## Project Overview

Paradise Nursery is designed to bring greenery closer to homes by providing an intuitive platform for exploring different categories of plants, managing a shopping cart, and proceeding to checkout.

## Features

- **Landing Page**: Features an inviting background image, company mission/about section, and a "Get Started" button leading directly to the plant collection.
- **Product Listing**: Categorized plants (e.g., Air Purifying, Aromatic, Medicinal) displaying image, name, description, and price.
- **Interactive Shopping Cart**: Dynamic cart total, capability to add items, increment/decrement quantities, remove items, or clear the cart.
- **State Management**: Built using **Redux Toolkit** for predictable and centralized global state management across components (`CartSlice.jsx`).

## Tech Stack

- **Frontend**: React (Vite / CRA)
- **State Management**: Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
- **Styling**: CSS3
